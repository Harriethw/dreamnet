# Section 3. More resources

I was first inspired to research technology like this by Lori Emerson’s work with Other Networks https://othernetworks.net/ 

I’ve already mentioned the fantastic hydroponic trash blog which inspired this zine and which gave me the blueprint for the network https://blog.hydroponictrash.solar/offgridinternet/ 

You can even repurpose a disposable vape and start running a server https://bogdanthegeek.github.io/blog/projects/vapeserver/

Iffy books have some incredible instructional intro zines https://iffybooks.net/zines/

Mastodon is a great social network to start going down the rabbit hole for things like this - you can sign up and start following hashtags like #indieweb #solarpunk #lowtech and more!
